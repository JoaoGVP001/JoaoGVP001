# Ícones

Ícones SVG originais da coleção [Devicon](https://github.com/devicons/devicon), na revisão `6a37858047b0e8d9c9c0e68f4a071fc410652e89`.

Os arquivos ficam neste repositório para que o perfil não dependa de um CDN de ícones. A licença da coleção está em [LICENSE.devicon.txt](./LICENSE.devicon.txt). Os logotipos pertencem às respectivas marcas.

CustomTkinter aparece apenas em texto no perfil: a coleção utilizada não oferece um ícone próprio para essa biblioteca.
